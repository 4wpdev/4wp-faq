# 4WP FAQ 2.4.0

**Published:** 2026-09-11
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

The FAQ Categories nav collapses nested terms by default so a deep tree stays short. Visitors expand the parents they need; the browser remembers their choice. The branch for the current category stays open.

## Highlights

- **Collapse subcategories** — on by default in the Categories block inspector. Turn it off to keep the full tree open.
- **Remembered state** — expand/collapse is stored in the visitor’s browser (`localStorage`).
- **Active branch** — the parent of the current category stays open so you do not lose your place.
- **Hub title & description** — pretty category URLs fill core Title / Query Title / Term Name and Excerpt / Term Description. Heading level stays with the template.
- **Canonical** — `/hub/term-slug/`, not the hub page.
- **SEO image** — category Open Graph image; empty uses the hub page image.
- **No duplicate H2** — the List skips the group title when the page heading already shows that category.
