# 4WP FAQ 2.5.0

**Published:** 2026-09-16
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

Optional AI Assistant generates FAQ category Description, Display title, SEO title, and SEO description through the standard **WordPress AI Client** (Settings → Connectors). No custom vendor SDK.

## Highlights

- **WordPress Connectors** — `wp_supports_ai()` / `wp_ai_client_prompt()`. Configure a text-generation connector first.
- **Opt-in** — **FAQ → Settings → AI** → Allow predefined field markup.
- **Category edit** — Generate with AI fills the mapped fields. Apply writes into the form; Update still saves.
- **Context** — category name plus questions in that term (registry titles). Review before saving.
