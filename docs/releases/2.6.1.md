# 4WP FAQ 2.6.1

**Published:** 2026-09-20
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

4WP FAQ now registers its accordion wrap with **4WP Drive**, so an imported Google Doc or Markdown FAQ section can become a `forwp/faq` block.

## Highlights

- Drive Patterns → Integrations Plugins shows **4WP FAQ** when this plugin is active.
- Heading 2 = FAQ section (any language; titles are set in Drive Patterns). Heading 3 = question; body = answer.
- [4WP Drive on WordPress.org](https://wordpress.org/plugins/4wp-drive/).
