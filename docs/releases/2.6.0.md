# 4WP FAQ 2.6.0

**Published:** 2026-09-18
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

The FAQ registry can now **edit** and **add** items, then write them onto the pages that already have `forwp/faq` blocks. Accordion content on the site stays the source of truth. A scan still rebuilds the registry from that content.

## Highlights

- **Edit:** Update a registry FAQ (title + answer). The plugin finds the accordion item on every **Used In** page (previous title if you renamed the question) and replaces Q/A.
- **Add FAQ:** question + answer. FAQ categories append the item to every matching FAQ block. **One page** (optional) targets a single post/page that already has a FAQ block. Neither: the row is registry-only until a scan drops it.
- New answers copy a sibling accordion-item wrapper and fill in your text; that markup is saved back on the registry record.
- Delete the CPT or reinstall: Rescan restores the list from the site.
