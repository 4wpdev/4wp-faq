# 4WP FAQ 2.1.0

**Published:** 2026-09-01
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

4WP FAQ wraps core Accordion with FAQPage JSON-LD and an optional question registry. Version **2.1.0** adds Site Editor blocks so you can build a glossary-style FAQ hub from that registry.

## Highlights

### For editors / site builders

- **4WP FAQ List** — grouped or flat list of registry questions.
- **4WP FAQ Card** — accordion or heading + answer; optional “Used in” source links.
- **4WP FAQ Categories** — nav that filters the list in place (no reload).
- Shared include/exclude between List and Categories; **All categories** shows the synced set.
- Optional SEO-friendly category URLs (`/page/term-slug/`).
- Core **Search** can filter the FAQ list without submitting a search.

### For SEO

- FAQPage JSON-LD still comes from in-place Accordion wrappers.
- When **Yoast SEO** is active, FAQ nodes merge into Yoast’s schema graph.

## Longer post (blog / newsletter)

4WP FAQ stays a thin layer on core Accordion: keep your design, add FAQPage JSON-LD, and optionally aggregate questions into a registry. **2.1.0** is for sites that want a public FAQ hub, not only in-page accordions.

After setup and a rescan, insert **4WP FAQ Categories** and **4WP FAQ List** in the Site Editor. The nav filters the list in place. Cards can show source pages (“Used in”). Category URLs and related Search are optional.

Install or update from WordPress.org, complete **FAQ → Settings** if you use the registry, rescan, then add the new blocks to a template or page.
