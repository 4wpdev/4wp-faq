## Blocks section shows 1 block

ZIP `2.1.0` includes `blocks/faq-list|faq-card|faq-categories/block.json`. The directory parser only treats a `block.json` as a listed block when it has `file:` assets (`editorScript` / `style`). Root `block.json` has them; hub blocks register scripts in PHP only.

**Fix in 2.2.0:** add `editorScript` and `style` paths relative to each hub `block.json` (`file:../../build/…`). Public listing: wrapper + List + Categories. Card can remain inner-only.
