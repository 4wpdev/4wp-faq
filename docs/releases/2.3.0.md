# 4WP FAQ 2.3.0

**Published:** 2026-09-03
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

## Summary

Filled category SEO titles stay exact. The FAQ admin Dashboard shows registry status, Rescan, and a collapsible category tree. Drag-and-drop FAQ category order on the taxonomy screen drives admin lists and the front-end hub. Settings explain how category titles are built.

## Highlights

- **SEO title** — if the category field is filled, no “ – site name” suffix.
- **Dashboard** — FAQ Status (with Rescan), By category (hierarchy, inclusive counts, remembered collapse), Most reused, Uncategorized.
- **Category order** — drag rows on FAQ Categories; order applies in admin and on List / Categories blocks (auto-adds `term_order` when the DB column is missing).
- **Settings** — compact toggles plus H1 / document title / meta description rules.
- **Styles** — Question / Answer typography for List/Card on the block Styles tab.
- **Docs** — hub blocks, Search filter, expanded WordPress.org FAQ.
