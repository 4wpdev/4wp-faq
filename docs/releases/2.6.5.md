# 4WP FAQ 2.6.5

**Published:** 2026-10-15
**WordPress.org:** https://wordpress.org/plugins/4wp-faq/

WordPress.org was on **2.6.1**. This release also delivers **2.6.2–2.6.4**.

## Summary

4WP FAQ wraps the core Accordion, adds FAQPage JSON-LD, and keeps one registry of the questions already on your pages.

## Highlights

- Hub filter no longer treats the host page slug as a FAQ category.
- Convert to FAQ keeps Accordion items; Unwrap restores Accordion or Details.
- Editor previews for List, Categories, and Count load again.
- Directory listing: animated banner and icon, nine screenshots.
